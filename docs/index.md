## API reference (GitHub Pages)

Hosted DocC documentation is published under `docs/api/` on each **stable** release. After Pages is enabled on the public repository, the entry URL is:

`https://hgsns.github.io/HigoCore/api/documentation/higocore`

Until the first stable release with DocC, browse API symbols in Xcode (**Product → Build Documentation**) after adding the package to your project.

## Minimum requirements

- iOS 17.0+
- Swift 5.9+
- Bluetooth permission for Higo device flows
